# BillManager v4.13.5

## Changes

- Report the actual usage for unlimited tier limits. `check_tier_limit`
  returned `used: 0` without counting whenever a limit was unlimited (`-1`),
  so `GET /api/v2/billing/usage` told Pro accounts they had 0 bills. The
  mobile Plan and billing screen showed "0 · Unlimited" next to a full bill
  list. It now counts active (non-archived) bills in databases the user owns
  and returns that count with `unlimited: true`. Responses keep the same keys,
  and an unlimited limit still always allows the action. The web Billing page
  shows only "Unlimited" for unlimited limits, so it does not change.

## Upgrade notes

- No database schema migration and no new configuration.
- The OpenAPI contract is unchanged apart from its version.
- An unlimited-limit check now runs one count query, the same query a limited
  tier already runs.
- This is the web/server release lane. Mobile-only changes merged since
  4.13.4 (iOS Hermes `Intl` fixes, Expo SDK 58 patch updates, and iOS capture
  tooling) require a separate signed mobile build and store review. This
  release does not establish mobile store availability.
