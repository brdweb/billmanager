# BillManager v4.13.2

## Changes

- Fixed mobile Insights ranges. 6 months, 12 months, and Yearly now drive
  income, bills, net cash flow, projected balance, and the forecast. Every
  scheduled recurrence in the window is projected, instead of a single next
  occurrence of each bill.
- Fixed mobile Analytics ranges. 6 months and 12 months are the next 6 or 12
  months starting today, half-open `[today, today + N months)`. Yearly is the
  selected calendar year: dates before today use recorded payments, and today
  through 31 December uses the schedule, so a payment already recorded today
  is not added on top of today's occurrence. Cash flow no longer replaces the
  current month with a projection from the first of the month, so payments
  already recorded this month stay in the total.
- Fixed shared-bill payment direction on `/stats/yearly`,
  `/stats/monthly-comparison`, and `/stats/by-account`. A payment a sharee
  made on the owner's expense bill counts as income for the owner, and the
  sharee sees that payment as their own expense. `/stats/monthly` and
  `/payments` already classified those payments correctly.
- Documented mobile crash reporting in `apps/mobile/docs/crash-reporting.md`
  and cross-linked it from `TELEMETRY.md`, `apps/mobile/README.md`, and
  `docs/server-crash-reporting.md`.
- Refreshed server dependencies: sentry-sdk 2.72.0, authlib 1.9.1, certifi
  2026.10.19.
- Refreshed web dependencies: Mantine 9.7.2, React 19.3.1, i18next 26.4.6 /
  react-i18next 17.0.18, Playwright 1.64.1, Vitest 5.0.5, jsdom 30.1.3,
  swagger-ui-dist 5.33.3, jspdf-autotable 5.0.9, Node 24.22.0-slim, and
  follow-redirects 1.16.1.
- Refreshed mobile dependencies without changing the app version: React
  Navigation 7.21, TanStack Query 5.104.3, lucide-react-native 1.57.0,
  react-hook-form 7.90.0, zod 4.6.7, Vitest 5.0.5, and Expo SDK 57 patches
  (expo ~57.0.31, @expo/ui ~57.0.26, expo-sharing ~57.0.24, expo-widgets
  ~57.0.27).
- Dependabot pull requests that edit `apps/server/requirements.txt` now
  recompile `apps/server/requirements.lock` for the changed direct
  requirements.

## Upgrade notes

- No configuration or schema changes.
- Yearly, monthly-comparison, and by-account totals can change for shared
  bills: a sharee's payment on the owner's expense is income for the owner
  and the sharee's own expense.
- The mobile Insights and Analytics fix reaches devices only through a future
  mobile build. This release publishes the server/web container and leaves
  the mobile app version unchanged.
