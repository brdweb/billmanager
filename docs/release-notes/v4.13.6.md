# BillManager v4.13.6

## Changes

- Offer web checkout after a terminal subscription (#302). The web Billing
  page showed pricing and **Get Pro** only when there was no stored
  subscription, so customers whose subscription had ended could resubscribe
  only from mobile or the API. Pricing now also shows for `canceled` and
  `incomplete_expired`; `past_due`, `unpaid`, `incomplete` and `paused` keep
  the portal path.
- Localize the checkout refusal (#302). `POST /api/v2/billing/create-checkout`
  now returns `code: "subscription_needs_attention"` when a non-terminal
  subscription blocks checkout. Its English message mentions the billing
  portal only when this user can open it. Web and mobile show English or
  German text by that code.
- Show no renewal date for ended subscriptions and label scheduled
  cancellations (#304). `billing/status` reports `cancel_at_period_end: false`
  for ended subscriptions. The web Billing page hides the period-end row for
  them, and a live subscription set to cancel shows **Cancels on**.
- Dependency updates: Authlib 1.9.5 (#305), sentry-sdk 2.74.0 and resend
  2.52.0 (#307), psycopg 3.3.8 (#309), web dependencies (#306, #310) and
  mobile dependencies (#308).

## Upgrade notes

- No database schema migration and no new configuration.
- The OpenAPI contract documents the new refusal `code` on the existing
  `ErrorResponse.code` field; no response shape changes.
- This is the web/server release lane. The mobile parts of #302 and #304
  (localized refusal, "Cancels" label) need a separate signed mobile build
  and store review. iOS 1.2.0 build 18 and Android code 13 predate them; older
  mobile clients still show the server's English message.
