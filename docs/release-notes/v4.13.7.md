# BillManager v4.13.7

## Changes

- Return Apple sign-ins from the iOS app to the app (#328, #329). Apple answers
  with a form POST to `/auth/callback`. The iOS sign-in sheet matches its
  return address by URL alone, so the server now forwards form_post answers
  for sign-ins the iOS app started to `/auth/callback/complete`, where the
  app waits. Web and Android callbacks keep `/auth/callback`.
- Dependency updates: Gunicorn 27.0.1 (#333), Stripe SDK 17.0.0 (#334),
  psycopg 3.3.9, sentry-sdk 2.75.0 and resend 2.53.2 (#330), i18next 27 and
  react-i18next 18 on the web (#332), web dependencies (#325), the Node 24.22.3
  container image (#317) and mobile dependencies (#331).

## Upgrade notes

- No database schema migration and no new configuration.
- Gunicorn 27 rejects malformed HTTP/1.1 requests that 26 accepted, such as a
  `Transfer-Encoding` that does not end in `chunked`. Reverse proxies send
  well-formed requests; a client that talks to Gunicorn directly with
  `Transfer-Encoding: identity` must stop sending it.
- This is the web/server release lane. The iOS app side of the sign-in fix
  (#329) and the mobile billing change (#336) need a separate signed mobile
  build and store review. iOS 1.2.0 build 18 and Android code 13 predate them.
